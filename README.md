### ⚡ Selected Engineering Highlights

- **Multi-Agent LLM Pricing Engine & Enterprise RAG** — Architected enterprise retrieval pipelines and multi-agent workflow engines via high-throughput FastAPI microservices at Revionics, reducing domain document resolution time by **70%+**.
- **Low-Latency Inference & Cloud Optimization** — Developed containerized REST APIs deployed via Docker on Kubernetes, slashing latency by **>80%** and cutting cloud compute expenses by **$100k+/year**.
- **Entity Resolution at Scale** — Eliminated **95%+** of manual data linkage by training and optimizing Siamese neural networks with triplet loss, paired with Leiden graph clustering across enterprise datasets.
